# Themba V10 — 3-minute judge script

**0:00-0:30 / The problem:** Stokvels let communities save together, but checking contributions, approving rotating payouts and resolving disputes often depends on fragmented records.

**0:30-0:55 / The product:** Themba provides one familiar savings interface, with language options and low-tech menus. Members see rand amounts and clearly marked pending/verified payment statuses.

**0:55-1:45 / Main demo:** Create or select a test stokvel, make a simulated contribution, request a payout, attempt self-approval (blocked), switch to two different authorized signers, approve, and inspect the demo audit. Reserve funds stay separate.

**1:45-2:20 / On-chain direction:** Show Invisible Web3 Proof Lab. Explain real smart account/Paymaster design and compare existing Safe integration with testnet-only candidate vault. If team has a real Sepolia contract transaction, show verifiable evidence; otherwise say clearly that deployment remains.

**2:20-2:45 / Inclusion:** Show USSD language menu, SMS and IVR examples. Stress that real network providers are not connected yet.

**2:45-3:00 / Business:** Free core records + paid group tools, optional partnerships; start with existing bank accounts, avoid real funds custody initially.

DO NOT CLAIM unverified Sepolia payout execution, gas sponsorship, inflation-beating yield, live USSD or real customer revenue.
