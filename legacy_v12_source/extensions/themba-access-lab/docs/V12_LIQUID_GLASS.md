# Themba V12 — Liquid Glass design update

Source visual direction: six user-provided reels (30 October 2026) documented in the saved `premium-interface-design` skill.

Preserves Themba forest green + champagne gold, savings photography, data and financial logic from V11.

Refraction: bounded backdrop-filter blur(14px) on the four primary actions and identity controls.
Rim: translucent borders and inset top highlights.
Reflections: pointer-reactive specular radial light, decorative only.
Responsive: reduced-motion, low-data and no-backdrop fallbacks.
The dashboard, approvals, contributions, USSD/SMS, audit and Web3 evidence demos are not connected to production funds.

No original GitHub files changed. These files are for a separate review deployment.
